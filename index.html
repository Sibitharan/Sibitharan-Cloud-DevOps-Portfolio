04 — DEVOPS PROJECT

Production-Ready Cloud & DevOps Portfolio

THE OBJECTIVE

Build and deploy a production-ready personal portfolio using AWS cloud services and a secure CI/CD pipeline.

THE IMPLEMENTATION

Designed a static cloud-hosted portfolio architecture using Amazon S3 for website hosting and Amazon CloudFront for global content delivery. Automated deployments using GitHub Actions with AWS IAM OIDC authentication.

AWS S3 Amazon CloudFront AWS IAM GitHub Actions OIDC CI/CD HTML CSS JavaScript Formspree GitHub

AWS S3 Hosting

Hosted the static portfolio website using Amazon S3 cloud storage.

CloudFront CDN

Delivered website content through Amazon CloudFront for reliable global content distribution.

OIDC Authentication

Configured GitHub Actions with AWS IAM OIDC federation to avoid storing long-lived AWS access keys.

CI/CD Automation

Automated website deployment from GitHub to AWS whenever changes are pushed to the main branch.

Git-Based Workflow

Used GitHub for source control, version management and automated deployment workflows.

Working Contact Form

Integrated Formspree to receive messages submitted through the portfolio contact form.

Portfolio Deployment Architecture

Source code is maintained in GitHub. GitHub Actions automatically authenticates with AWS using OIDC and assumes an IAM role. The workflow uploads website files to Amazon S3 and distributes the application through Amazon CloudFront.
